# 📊 CorpTech ITSM Analytics

## 📌 Descrição do Projeto
O **CorpTech ITSM Analytics** é uma plataforma voltada para análise de dados de suporte de TI, utilizando informações extraídas do Jira Service Management (JSM) e transformadas em dashboards no Power BI por meio de uma arquitetura baseada em Azure.

---

## ⚠️ Problema de Negócio

A CorpTech enfrenta dificuldades em extrair inteligência dos dados registrados no Jira Service Management. Apesar de todos os chamados estarem centralizados na ferramenta, os relatórios disponíveis são limitados e exigem exportações manuais.

Principais dificuldades:

- Falta de visão consolidada de SLA por categoria, analista e cliente  
- Ausência de painel externo para visualização de backlog e filas  
- Inexistência de análise histórica de volume e tendências  
- Falta de monitoramento estruturado de desempenho da equipe (MTTR e MTTA)  
- Dados de satisfação do cliente (CSAT) não são analisados de forma integrada  

Essas limitações impactam a tomada de decisão da liderança de TI.
